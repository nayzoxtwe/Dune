# Frontend Styleguide
- Dark theme baseline with background `#0B0B0F` and neutral text tokens.
- Chat bubbles respect Tailwind recipe: gradient violet self bubbles, deep gray others.
- Shared CSS variables: `--bubble-radius`, `--bubble-shadow`, `--accent`, `--bg-0`, `--bg-1`.
- Accessibility: focus-visible outlines, WCAG AA contrast checks baked into tokens.
